# DropQR — Serverless QR Media & Data Collection Portal

DropQR is a client-side web utility that streamlines gathering photos, notes, and custom metadata from event attendees, clients, or finders—without forcing scanners to install an app or create an account.

### Key Features
- **Dynamic Link Encoding:** Configuration parameters (target email, title, requested fields) are encoded directly into the QR payload via URL query strings.
- **100% Serverless & Private:** Runs entirely in the browser with zero backend infrastructure or external database dependencies.
- **Native Mail Client Integration:** Seamlessly compiles user-submitted data into standard URI protocols (`mailto:`) to draft pre-formatted messages directly in the sender's default email client.
- **One-Click Export:** Download generated QR codes as PNG assets for print or digital distribution.

### Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Libraries:** QRCode.js
- **Deployment:** GitHub Pages
